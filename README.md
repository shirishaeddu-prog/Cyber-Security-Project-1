Web Application Vulnerability Scanner

Introduction

The Web Application Vulnerability Scanner is a Python-based project used to perform basic security checks on websites.

Objective

To identify missing security headers and check the basic security configuration of a website.

Tools Used

- Python
- Pydroid 3
- urllib library

Features

- Accepts website URL from the user.
- Checks website status code.
- Checks important security headers.
- Displays missing security headers.
- Generates a simple scan report.

Steps Involved

1. Open Pydroid 3.
2. Write the Python code.
3. Enter the website URL.
4. The program checks the website response.
5. It checks security headers.
6. Displays the scan results.

Output

- Website URL
- Status Code
- Security Headers Present
- Missing Security Headers
- Scan Completed Message

Conclusion

This project helps beginners understand basic website security testing and security headers using Python.
